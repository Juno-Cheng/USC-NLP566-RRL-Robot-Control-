# USC-NLP566-RRL-Robot-Control-

# Pre-requisites 
1. Docker

# Commands to Run Docker Container 
1. Change into the directory where you have cloned the repo. Change into "Docker" directory in the repo.

Run the following command:
    'batch docker build -t my_container .'

This will pull the image. After the image is pulled start it as a container.

Run the following command: 'docker run -it my_container'

_Note: To see if docker container is running successfully type 'docker ps' in a command prompt or powershell terminal._
